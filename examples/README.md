# Examples

Readable references. The main build formats them but does not compile them.

| File | Shows |
|---|---|
| [`MinimalExample.java`](MinimalExample.java) | Fetch the user and print the balance. |
| [`ErrorHandlingExample.java`](ErrorHandlingExample.java) | Handle `RATE_LIMITED` and `COOLDOWN`. |
| [`AltManagerExample.java`](AltManagerExample.java) | List stock, ask about a referral code, purchase, and pass the result to your app. This spends balance. |

Read the [disclaimer](../DISCLAIMER.md) before running any of them.
